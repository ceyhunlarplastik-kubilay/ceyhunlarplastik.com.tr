# Customer portal cart load planning

The customer-facing fill indicator uses business planning capacities rather than nominal internal volumes:

| Carrier | Planning capacity | Informational reference |
| --- | ---: | --- |
| Euro pallet equivalent | 2.6 m³ | EPAL 1 base: 1,200 × 800 mm; there is no fixed nominal volume |
| 20' standard container | 33 m³ | 33.2 m³ nominal |
| 40' standard container | 59 m³ | 67.7 m³ nominal |
| 40' high-cube container | 69 m³ | 76.4 m³ nominal |
| 13.6 m curtain-side truck | 83 m³ | about 90.5 m³ from example internal dimensions; vehicle-dependent |

References reviewed on 2026-08-28:

- [EPAL Euro pallet specification](https://www.epal-pallets.org/eu-en/load-carriers/epal-euro-pallet)
- [Maersk container capacity reference](https://www.maersk.com/tr-tr/support/faqs/2023/10/09/cargo-weight-limit)
- [Schmitz Cargobull S.CS Universal technical sheet](https://www.cargobull.com/kz/-/media/project/scb-sites/scb-global-site/media-center-en/brief-information-scs-universal--kp.pdf)

This first version is a full-package volume estimate, not a 3D loading guarantee. Rotation, stackability, payload limits and physical placement are intentionally outside its scope.
